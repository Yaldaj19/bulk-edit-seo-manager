## 🎯 معرفی

**ویرایش گروهی پست تایپ‌ها** یک پلاگین حرفه‌ای وردپرس است که امکان ویرایش همزمان صدها پست، محصول یا هر پست‌تایپ سفارشی را در یک صفحه فراهم می‌کند. این پلاگین با رابط کاربری مدرن و قدرتمند، سرعت کار شما را تا **95%** افزایش می‌دهد.

### 🎁 چرا این پلاگین؟

- ⚡ **سرعت فوق‌العاده**: ویرایش صدها آیتم در چند دقیقه
- 🎨 **رابط کاربری مدرن**: طراحی زیبا و کاربرپسند با Row Scroll System
- 🔍 **یکپارچگی کامل**: سازگار با Yoast SEO و Rank Math
- 🛍️ **پشتیبانی ووکامرس**: مدیریت حرفه‌ای محصولات و variations
- 🌐 **کاملاً فارسی**: تمام بخش‌ها به زبان فارسی با پشتیبانی کامل از نامک فارسی
- 🔒 **امنیت بالا**: استانداردهای امنیتی وردپرس
- 🖼️ **مدیریت پیشرفته تصاویر**: آپلود، جایگزینی خودکار و مدیریت گالری

## 🚀 ویژگی‌های کلیدی

### ✨ قابلیت‌های پایه

#### 📦 مدیریت پست‌تایپ‌ها
- ✅ پشتیبانی از **تمام پست‌تایپ‌های وردپرس** (پست، صفحه، محصول)
- ✅ پشتیبانی از **پست‌تایپ‌های سفارشی** (Custom Post Types)
- ✅ ویرایش **نامحدود** آیتم‌ها در یک صفحه
- ✅ انتخاب **دلخواه فیلدها** برای نمایش و ویرایش
- ✅ ذخیره‌سازی **گروهی** با یک کلیک

#### 🎯 فیلترهای هوشمند
- 🔍 **جستجوی متنی** در عنوان و محتوا
- 📊 فیلتر بر اساس **وضعیت انتشار** (منتشر شده، پیش‌نویس، خصوصی، در انتظار)
- 🏷️ فیلتر **تگزونومی‌ها** (دسته‌بندی، برچسب و سایر تگزونومی‌های سفارشی)
- 🛍️ فیلتر **نوع محصول** ووکامرس (ساده، متغیر، گروهی، خارجی)
- ⚙️ **فیلترهای پیشرفته متافیلدها** - شناسایی خودکار و فیلتر بر اساس متافیلدها
- 📈 تعداد نمایش **قابل تنظیم** (25، 50، 100، 200 آیتم)

#### 🎨 رابط کاربری مدرن
- 🖥️ **Row Scroll System** - هر سطر به صورت مستقل اسکرول افقی دارد
- 📌 **Sticky Header** - هدر جدول همیشه در دسترس
- 🔄 **Header Sync** - همگام‌سازی خودکار هدر با اسکرول سطرها
- 📱 طراحی **واکنش‌گرا** (Responsive) برای تمام دستگاه‌ها
- 🎭 **انیمیشن‌های نرم** و حرفه‌ای
- 🌈 استایل **مدرن** و چشم‌نواز
- ⚡ عملکرد **سریع** و بهینه
- 💡 راهنمای **جامع** در همان صفحه

- 🏷️ ویرایش **Alt Text** برای هر تصویر

### 🔍 یکپارچگی کامل با پلاگین‌های سئو

#### Yoast SEO
قابلیت ویرایش گروهی تمام فیلدهای زیر:
- 📝 **عنوان سئو** (SEO Title)
- 📄 **توضیحات متا** (Meta Description)
- 🔑 **کلمه کلیدی فوکوس** (Focus Keyword)
- 🔗 **لینک کانونیکال** (Canonical URL)
- 🚫 **No Index** - عدم نمایش در موتورهای جستجو
- 🔗 **No Follow** - عدم دنبال کردن لینک‌ها

#### Rank Math
قابلیت ویرایش گروهی تمام فیلدهای زیر:
- 📝 **عنوان سئو** (SEO Title)
- 📄 **توضیحات متا** (Meta Description)
- 🔑 **کلمه کلیدی فوکوس** (Focus Keyword)
- 🔗 **لینک کانونیکال** (Canonical URL)
- 🚫 **No Index** - عدم نمایش در موتورهای جستجو
- 🔗 **No Follow** - عدم دنبال کردن لینک‌ها

#### مزایای یکپارچگی
- ⚡ **ذخیره‌سازی فوری** تغییرات سئو
- 🔄 **همگام‌سازی کامل** با پلاگین‌های سئو
- 📊 تاثیر **بلافاصله** روی رتبه‌بندی
- 🎯 بهینه‌سازی **گروهی** صدها صفحه

### 🛍️ محصولات متغیر ووکامرس

#### شناسایی خودکار
- 🎯 **تشخیص خودکار** محصولات Variable
- 📂 نمایش **Variations** به صورت تو در تو با طراحی زیبا
- 🎭 **انیمیشن نرم** برای باز/بسته کردن
- 🎨 طراحی **مدرن** و قابل تشخیص

#### ویرایش مستقل Variations

- 🖼️ **تصویر اختصاصی**
- 💰 **قیمت عادی** و **قیمت ویژه**
- 🏷️ **SKU** (شناسه محصول)
- 📦 **تعداد موجودی**
- ✅ **وضعیت موجودی** (موجود، ناموجود، در انتظار تامین)
- 📝 **توضیحات** اختصاصی

#### ذخیره‌سازی امن
- 💾 ذخیره **جداگانه** هر Variation
- 🔒 **محافظت** از داده‌های محصول اصلی
- ⚡ آپدیت **همزمان** محصول و Variations
- 🔄 **بازگشت خودکار** در صورت خطا

## 💾 نصب و راه‌اندازی

### روش 1: نصب از طریق پنل وردپرس

1. به **پیشخوان وردپرس** بروید
2. از منوی **افزونه‌ها** گزینه **افزودن** را انتخاب کنید
3. روی **بارگذاری افزونه** کلیک کنید
4. فایل ZIP پلاگین را انتخاب و آپلود کنید
5. روی **نصب** و سپس **فعال‌سازی** کلیک کنید

### روش 2: نصب دستی
```bash
# 1. دانلود پلاگین
git clone https://github.com/Yaldaj19/bulk-edit-seo-manager.git

# 2. کپی به پوشه plugins
cp -r bulk-edit-seo-manager /path/to/wordpress/wp-content/plugins/

# 3. تنظیم مجوزها
chmod -R 755 /path/to/wordpress/wp-content/plugins/bulk-edit-seo-manager
```

سپس از پنل مدیریت وردپرس پلاگین را فعال کنید.

## 🎓 راهنمای سریع

### مرحله 1: تنظیمات اولیه (30 ثانیه)

1. از منوی **ویرایش گروهی پست تایپ ها** وارد **تنظیمات** شوید
2. یک **نوع پست** انتخاب کنید (مثلاً: محصول، پست، صفحه)
3. **فیلدهای مورد نظر** را برای نمایش در لیست انتخاب کنید
4. **تعداد نمایش** در هر صفحه را تعیین کنید (50 پیش‌فرض)
5. روی **ذخیره تنظیمات و تایید** کلیک کنید

### مرحله 2: استفاده از فیلترها (1 دقیقه)

1. به صفحه **ویرایشگر گروهی** بروید
2. از بخش فیلترها استفاده کنید:
   - 🔍 **جستجو**: برای یافتن سریع آیتم‌ها
   - 📊 **وضعیت**: فیلتر بر اساس وضعیت انتشار
   - 🛍️ **نوع محصول**: فیلتر محصولات ووکامرس
   - 🏷️ **دسته‌بندی/برچسب**: فیلتر تگزونومی‌ها
3. روی **فیلترهای پیشرفته** کلیک کنید برای دسترسی به:
   - 📂 فیلتر **تگزونومی‌های سفارشی**
   - ⚙️ فیلتر **متافیلدها**
4. روی **اعمال فیلتر** کلیک کنید

### مرحله 3: ویرایش گروهی (2 دقیقه)

1. **مشاهده لیست**: آیتم‌های فیلتر شده نمایش داده می‌شوند
2. **اسکرول افقی**: هر سطر را به راست/چپ اسکرول کنید
3. **Header Sync**: هدر به صورت خودکار با اسکرول سطر همگام می‌شود
4. **ویرایش فیلدها**: مستقیماً در جدول تایپ کنید
5. **مدیریت تصاویر**:
   - روی باکس تصویر کلیک کنید
   - تصویر جدید انتخاب کنید
   - Alt Text خودکار پر می‌شود
6. **گالری تصاویر**:
   - روی دکمه + کلیک کنید
   - چند تصویر را انتخاب کنید
   - تصاویر خودکار اضافه می‌شوند
7. **محصولات متغیر**:
   - روی دکمه فلش کنار ID کلیک کنید
   - Variations با انیمیشن نرم نمایش داده می‌شوند
   - هر Variation را جداگانه ویرایش کنید

### مرحله 4: ذخیره تغییرات (10 ثانیه)

1. روی دکمه **ذخیره تغییرات** کلیک کنید
2. **Loading Overlay** نمایش داده می‌شود
3. منتظر بمانید تا پیغام موفقیت نمایش داده شود
4. صفحه خودکار بارگذاری مجدد می‌شود

## 🎯 قابلیت‌های پیشرفته

### 🎨 Row Scroll System

#### چیست؟
سیستم نوآورانه‌ای که به شما امکان می‌دهد هر سطر جدول را به صورت **مستقل** به راست و چپ اسکرول کنید.

#### چرا مفید است؟
- 📊 مشاهده **فیلدهای بیشتر** در یک صفحه
- ⚡ **سرعت بالاتر** در ویرایش
- 🎯 **تمرکز** روی یک آیتم در هر لحظه
- 📱 **کاربردی** در صفحه‌نمایش‌های کوچک

#### نحوه استفاده
1. ماوس را روی هر سطر ببرید
2. Scrollbar افقی در پایین سطر ظاهر می‌شود
3. با ماوس یا تاچ‌پد اسکرول کنید
4. **Header به صورت خودکار همگام می‌شود**

---

### 🔄 Header Sync System

#### چیست؟
سیستم همگام‌سازی خودکار هدر جدول با اسکرول افقی هر سطر.

#### مزایا
- 📌 **همیشه می‌دانید** در چه ستونی هستید
- ⚡ **بدون نیاز** به اسکرول دستی هدر
- 🎯 **افزایش دقت** در ویرایش
- 💡 **تجربه کاربری عالی**

#### نحوه کار
1. وقتی سطری را اسکرول می‌کنید
2. Header به صورت **realtime** همگام می‌شود
3. می‌توانید **Header** را هم اسکرول کنید
4. تمام سطرها همگام می‌شوند

### 🔍 فیلترهای هوشمند متافیلدها

#### شناسایی خودکار
پلاگین به صورت خودکار:
- 🔎 تمام **متافیلدهای موجود** را شناسایی می‌کند
- 📊 **نوع داده** را تشخیص می‌دهد (متن، عدد، انتخابی)
- 🎨 **UI مناسب** را نمایش می‌دهد
- ⚡ فیلتر را **بهینه** اعمال می‌کند

1. **متن**: جستجوی LIKE در مقادیر

3. **انتخابی**: لیست کشویی مقادیر منحصر به فرد


### Hooks و Filters

#### Actions
```php
// قبل از ذخیره گروهی
do_action('besm_before_bulk_save', $posts_data);

// بعد از ذخیره گروهی
do_action('besm_after_bulk_save', $results);

// قبل از ذخیره هر پست
do_action('besm_before_save_post', $post_id, $post_data);

// بعد از ذخیره هر پست
do_action('besm_after_save_post', $post_id, $result);
```

#### Filters
```php
// فیلتر فیلدهای موجود
add_filter('besm_available_fields', function($fields, $post_type) {
    $fields['custom_field'] = array(
        'type' => 'text',
        'label' => 'فیلد سفارشی'
    );
    return $fields;
}, 10, 2);

// فیلتر آرگومان‌های query
add_filter('besm_query_args', function($args, $filters) {
    // تغییر query
    return $args;
}, 10, 2);

// فیلتر داده پست قبل از ذخیره
add_filter('besm_post_data', function($data, $post_id) {
    // تغییر داده
    return $data;
}, 10, 2);

// فیلتر گزینه‌های فیلتر
add_filter('besm_filter_options', function($options, $post_type) {
    // افزودن گزینه
    return $options;
}, 10, 2);
```

---

### مثال: افزودن فیلد سفارشی
```php
// افزودن فیلد سفارشی به لیست
add_filter('besm_available_fields', 'my_custom_field', 10, 2);
function my_custom_field($fields, $post_type) {
    if ($post_type === 'product') {
        $fields['my_custom_price'] = array(
            'type' => 'number',
            'label' => 'قیمت ویژه من'
        );
    }
    return $fields;
}

// ذخیره فیلد سفارشی
add_action('besm_after_save_post', 'save_my_custom_field', 10, 2);
function save_my_custom_field($post_id, $result) {
    if (isset($_POST['posts'][$post_id]['my_custom_price'])) {
        $value = sanitize_text_field($_POST['posts'][$post_id]['my_custom_price']);
        update_post_meta($post_id, '_my_custom_price', $value);
    }
}
```
